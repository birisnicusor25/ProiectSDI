# Sistem Distribuit de Stocare a Fisierelor

Autor:
Biris Nicolae

Descriere:
ProiectSDI este o aplicație distribuită pentru stocarea și gestionarea fișierelor pe mai multe noduri de stocare.

Sistemul utilizeaza un coordonator pentru gestionarea metadatelor si permite:

încărcarea fișierelor (put);
descărcarea fișierelor (get);
listarea fișierelor stocate (ls);
ștergerea fișierelor (rm);
afișarea stării nodurilor (nodes);
replicarea fișierelor pe două noduri distincte;
toleranță la defectarea unui nod;
adăugarea dinamică a nodurilor în sistem.
În Etapa 1 este implementat scheletul aplicației și mecanismul de configurare prin argumente din linia de comandă.
