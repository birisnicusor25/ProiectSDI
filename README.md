# Sistem Distribuit de Stocare Fisiere

Autor:
Biris Nicolae

Descriere:
Aplicatia implementează un sistem distribuit de stocare a fișierelor format din mai multe noduri de stocare și un client.

Caracteristici urmărite:
stocarea fișierelor pe mai multe noduri;
replicarea fiecărui fișier pe două noduri distincte;
păstrarea accesului la fișiere în cazul căderii unui nod;
descoperirea automată a nodurilor;
alegerea unui coordonator pentru gestionarea metadatelor;
transfer direct al fișierelor între client și noduri.
